# Introduction
This repository hosts all VARC HAM radio/Satellite RX station cross regions. Station is stored at the files `stations.txt` which in 3 line format
```bash
[{station owner's callsign}] [station name] [{lat},{lon}] [{public access url}]
[{antenna specification}]
[{main active frequency in Mhz}]
```

For example
```bash
[XV4HT/BN] [BluecyLabs RX Station - Bắc Ninh] [20.9993942,106.2050098] [https://bn-rx.bluecylabs.com]
[20m EFHW]
[14.07400,14.190]

[XV4HT] [BluecyLabs RX Station - Hà Nội] [20.979914,105.7543741] [https://rx.bluecylabs.com]
[1/4 WGP]
[1090,433,923]
```
